# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to the basic responsibilities of a cloud infrastructure engineer. I used the KillerCoda Playground to work inside an Ubuntu Linux environment and prepared a GitHub repository as my Cloud Computing Portfolio.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Create and organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Accessed an Ubuntu Linux environment through KillerCoda.
2. Created a new Linux user with a home directory, Bash shell, and sudo privileges.
3. Logged in using the newly created user account.
4. Checked the current username, working directory, and hostname.
5. Gathered information about the Linux distribution, kernel, CPU, memory, and disk space.
6. Created directories and Markdown files.
7. Created and organized the Cloud Computing Portfolio repository on GitHub.

## Linux Commands Used

- `whoami` - Displays the current username.
- `pwd` - Displays the current working directory.
- `hostname` - Displays the hostname.
- `uname -r` - Displays the kernel version.
- `lscpu` - Displays CPU information.
- `free -h` - Displays memory information.
- `df -h` - Displays disk space information.
- `mkdir` - Creates directories.
- `cd` - Changes the current directory.
- `ls` - Lists files and directories.
- `nano` - Creates and edits text files.
- `cat` - Displays file contents.
- `cp` - Copies files.
- `git clone` - Copies a Git repository to the local system.

## Skills Learned

Through this laboratory, I learned how to work with a Linux environment, navigate directories, gather system information, create and manage files, and document technical activities using Markdown. I also learned the basic process of creating and working with a GitHub repository.
