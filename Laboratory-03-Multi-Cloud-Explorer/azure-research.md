# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and application development.

## Global Infrastructure

Azure operates through a worldwide network of regions and datacenters. Azure regions contain datacenters that provide cloud services to customers in different geographic locations.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. It provides access to services such as virtual machines, storage, databases, networking, and security.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual servers for running applications and operating systems in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of unstructured data such as documents, images, videos, and backups.

### 3. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users and applications.

### 4. Azure Virtual Network

Azure Virtual Network allows cloud resources to communicate securely within an isolated virtual network.

## Three Advantages

1. Azure integrates well with Microsoft products and technologies.
2. It provides a wide range of services for enterprise and cloud applications.
3. Azure offers global infrastructure for organizations operating in different regions.

## Typical Enterprise Use Cases

Azure can be used for enterprise applications, Windows Server workloads, Microsoft 365-related environments, databases, virtual machines, application development, analytics, and artificial intelligence workloads.
