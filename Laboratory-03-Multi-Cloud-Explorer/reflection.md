# Mission 3 Reflection

## Introduction

Completing Mission 3 helped me understand how different cloud platforms can be used to solve different business and technical requirements. I explored AWS, Microsoft Azure, and Google Cloud Platform and compared their services, strengths, and possible use cases.

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most was Google Cloud Platform. I found its services for artificial intelligence, machine learning, data analytics, and Kubernetes particularly interesting. Google Cloud also provides scalable infrastructure that can support modern applications and cloud-native workloads.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP all provide essential cloud services such as virtual machines, object storage, databases, networking, and identity management. All three platforms also provide scalable infrastructure and services that allow organizations to deploy applications without managing all physical hardware themselves.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important when selecting a cloud provider because different organizations have different needs. Factors such as budget, existing technologies, performance, scalability, security, location, and application requirements can influence the final decision. A provider should be selected based on how well its services solve the organization's specific problems.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that choosing a cloud provider is not simply about selecting the most popular platform. A Cloud Solutions Consultant must understand the client's requirements, compare available services, and recommend a solution that provides the best balance of performance, scalability, cost, and compatibility.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub Cloud Computing Portfolio became more organized and contains more technical documentation. I learned how to document research, compare cloud services, analyze business scenarios, and use Git and GitHub to maintain my work. This mission also helped me become more comfortable working with Linux and cloud-related technologies.

## Conclusion

Overall, Mission 3 improved my understanding of multi-cloud environments and helped me see how cloud technologies can be matched to real-world business requirements. It also strengthened my documentation, Linux, research, and GitHub skills.
