# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides services for computing, storage, databases, networking, security, and many other IT needs. Organizations can use AWS to build, deploy, and manage applications without maintaining all of their own physical infrastructure.

## Global Infrastructure

AWS operates a large global infrastructure made up of Regions and Availability Zones. This allows organizations to deploy applications in different geographic locations and design systems for reliability and availability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create resources, configure services, monitor their environments, and manage security settings through the console.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers for running applications and workloads.
2. **Amazon S3** – Provides scalable object storage for files and other data.
3. **Amazon VPC** – Provides networking resources for creating isolated cloud networks.
4. **AWS IAM** – Manages users, roles, permissions, and access to AWS resources.

## Three Advantages

1. AWS provides a wide range of cloud services for different technical and business requirements.
2. AWS supports infrastructure that can scale as application workloads change.
3. AWS provides global infrastructure that allows applications to be deployed closer to their users.

## Typical Enterprise Use Cases

AWS can be used by enterprises for web applications, data storage, backup and disaster recovery, application development, databases, analytics, and large-scale business systems.
